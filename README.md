# WeChatLiquidTab (roothide)

微信消息分组栏（好友 / 群聊 / 服务号）液态玻璃质感定制与切换拦截插件。

## 构建方式
通过 GitHub Actions 自动编译（推荐）：
1. 提交或推送代码到 GitHub 仓库 `main` 分支。
2. 进入 Actions 页面查看 `build-wechat-liquid-tab` 工作流。
3. 构建完成后在 Artifacts 下载 `WeChatLiquidTab-roothide-deb`。

## 安装步骤 (roothide)
1. 使用 Sileo 安装导出的 `.deb`。
2. 打开 `RootHide Manager`，找到微信（WeChat），开启注入开关。
3. 重启微信即可生效。
